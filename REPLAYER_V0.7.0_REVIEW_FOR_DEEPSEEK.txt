1. ИСХОДНЫЕ ЗАДАЧИ ОТ ПОЛЬЗОВАТЕЛЯ
--------------------------------------------------------------------------------
Задача 1 (Настройки DLNA):
  "В настройках меню не выделять Доступные медиасерверы в сети в такой большой блок,
   если у нас уже один подключен. Сделать маленькой кнопкой внутри «Серверы DLNA»,
   при нажатии на которую появятся доступные, но ещё не подключенные серверы."

Задача 2 (Чистый проводник файлов):
  "Не подписывать пока разрешение или тип файла в папках. Всё и так наглядно на иконке
   (папка, видео, аудио и тд). На формат АВИ или МПЕГ конечному пользователю в целом плевать,
   если всё работает."

Задача 3 (Полноценный IPTV с программой передач):
  "Сделать ещё один раздел с IPTV. В настройки внести добавление формата .m3u и .m3u8,
   а также программы передач для них (EPG). Обычно подтягивается XML из сети (.xml и .xml.gz).
   Ориентиром в плане функционала держать в голове приложение Televizo."

Задача 4 (Главный экран в дизайне Android TV):
  "Держать курс в плане дизайна на Android TV. На главном экране:
   - Первая основная строка: текущие просматриваемые файлы из DLNA и избранные ТВ каналы из IPTV.
   - Вторая строка потоньше: избранные папки DLNA."

--------------------------------------------------------------------------------
2. АРХИТЕКТУРНЫЕ РЕШЕНИЯ И РЕАЛИЗАЦИЯ
--------------------------------------------------------------------------------
1) Потоковый парсинг M3U/M3U8 (M3uParser.kt):
   - Однопроходный построчный стриминг.
   - Извлечение атрибутов tvg-id, tvg-name, tvg-logo, group-title через регулярные выражения.
   - Автоматический поиск ссылки на телепрограмму в шапке плейлиста (#EXTM3U url-tvg="...").

2) Потоковый низкопотребляющий EPG XMLTV парсер (XmlTvParser.kt):
   - Использование XmlPullParser без загрузки DOM-дерева в память (предотвращает OOM на 50-100 МБ XMLTV).
   - Прозрачная поддержка сжатых архивов .xml.gz через GZIPInputStream.
   - Индексация программ по каналу (channel ID) и времени начала/конца.

3) Управление состоянием IPTV (IptvManager.kt):
   - Реактивное состояние через StateFlow: список каналов, группы/категории, избранные каналы, EPG.
   - Персистентность избранных каналов и ссылок в SharedPreferences.
   - Расчет текущей передачи с прогрессом воспроизведения в реальном времени.

4) История недавнего воспроизведения (RecentMediaManager.kt):
   - Сохранение последних 15 воспроизведенных элементов из DLNA с временными метками.

5) Главный экран в стиле полок Android TV (HomeScreen.kt):
   - Полка 1 (Hero Shelf, карточки 240x138dp): недавние фильмы DLNA + избранные ТВ-каналы с логотипами и передачей в эфире.
   - Полка 2 (Компактная полка, 220x68dp): закрепленные папки DLNA.

6) Экран IPTV (IptvScreen.kt):
   - Горизонтальная фильтрация категорий («Все», «Избранное», группы из плейлиста).
   - Список каналов с отображением текущей телепередачи и прогресс-баром эфира.
   - Быстрое переключение избранного (сердечко).
   - Мгновенный запуск потока в полноэкранном LibVLC плеере.

7) Оптимизация экрана настроек (SettingsScreen.kt):
   - Карточка активного DLNA с кнопками «Сменить сервер» (раскрывает список доступных) и «Отключить».
   - Секция «IPTV / Онлайн ТВ» с полями ввода M3U и EPG и валидацией.

8) Очистка UpnpBrowseScreen.kt:
   - Удалены бейджи технических форматов (AVI, MKV) из списочного и сеточного отображения.

package com.replayer.model

import kotlinx.serialization.Serializable

@Serializable
data class EpgProgram(
    val channelId: String,
    val title: String,
    val description: String? = null,
    val startTime: Long,
    val endTime: Long
) {
    fun isCurrent(now: Long = System.currentTimeMillis()): Boolean {
        return now in startTime..endTime
    }

    fun progress(now: Long = System.currentTimeMillis()): Float {
        if (endTime <= startTime) return 0f
        return ((now - startTime).toFloat() / (endTime - startTime).toFloat()).coerceIn(0f, 1f)
    }

    fun formattedTimeRange(): String {
        val s = java.text.SimpleDateFormat("HH:mm", java.util.Locale.getDefault())
        return "${s.format(java.util.Date(startTime))} - ${s.format(java.util.Date(endTime))}"
    }
}

package com.replayer.network.iptv

import com.replayer.model.IptvChannel
import java.io.BufferedReader
import java.io.InputStream
import java.io.InputStreamReader

data class M3uParseResult(
    val channels: List<IptvChannel>,
    val epgUrl: String?
)

object M3uParser {

    private val TVG_ID_REGEX = Regex("""tvg-id="([^"]*)"""", RegexOption.IGNORE_CASE)
    private val TVG_NAME_REGEX = Regex("""tvg-name="([^"]*)"""", RegexOption.IGNORE_CASE)
    private val TVG_LOGO_REGEX = Regex("""tvg-logo="([^"]*)"""", RegexOption.IGNORE_CASE)
    private val GROUP_TITLE_REGEX = Regex("""group-title="([^"]*)"""", RegexOption.IGNORE_CASE)
    private val URL_TVG_REGEX = Regex("""(?:url-tvg|x-tvg-url)="([^"]*)"""", RegexOption.IGNORE_CASE)

    fun parse(inputStream: InputStream): M3uParseResult {
        val reader = BufferedReader(InputStreamReader(inputStream, Charsets.UTF_8))
        val channels = mutableListOf<IptvChannel>()
        var detectedEpgUrl: String? = null

        var currentExtInf: String? = null
        var index = 0

        reader.forEachLine { rawLine ->
            val line = rawLine.trim()
            if (line.isEmpty()) return@forEachLine

            if (line.startsWith("#EXTM3U", ignoreCase = true)) {
                URL_TVG_REGEX.find(line)?.groupValues?.getOrNull(1)?.let {
                    val firstUrl = it.split(",", ";").firstOrNull()?.trim()
                    if (!firstUrl.isNullOrBlank()) {
                        detectedEpgUrl = firstUrl
                    }
                }
            } else if (line.startsWith("#EXTINF:", ignoreCase = true)) {
                currentExtInf = line
            } else if (!line.startsWith("#")) {
                // This is the stream URL
                val extInf = currentExtInf
                val streamUrl = line

                val tvgId = extInf?.let { TVG_ID_REGEX.find(it)?.groupValues?.getOrNull(1)?.trim() }
                val tvgName = extInf?.let { TVG_NAME_REGEX.find(it)?.groupValues?.getOrNull(1)?.trim() }
                val logoUrl = extInf?.let { TVG_LOGO_REGEX.find(it)?.groupValues?.getOrNull(1)?.trim() }
                val groupTitle = extInf?.let { GROUP_TITLE_REGEX.find(it)?.groupValues?.getOrNull(1)?.trim() }
                    ?.ifBlank { null } ?: "Общие"

                // Extract title after last comma
                val commaIdx = extInf?.lastIndexOf(',') ?: -1
                val title = if (commaIdx != -1 && extInf != null && commaIdx + 1 < extInf.length) {
                    extInf.substring(commaIdx + 1).trim()
                } else {
                    tvgName ?: "Канал ${index + 1}"
                }

                if (title.isNotBlank() && streamUrl.isNotBlank()) {
                    index++
                    val channelId = tvgId?.ifBlank { null } ?: "ch_${index}_${title.hashCode()}"
                    channels.add(
                        IptvChannel(
                            id = channelId,
                            name = title,
                            streamUrl = streamUrl,
                            logoUrl = logoUrl?.ifBlank { null },
                            group = groupTitle,
                            tvgId = tvgId?.ifBlank { null },
                            tvgName = tvgName?.ifBlank { null }
                        )
                    )
                }
                currentExtInf = null
            }
        }

        return M3uParseResult(channels = channels, epgUrl = detectedEpgUrl)
    }
}

package com.replayer.network.iptv

import android.util.Xml
import com.replayer.model.EpgProgram
import org.xmlpull.v1.XmlPullParser
import java.io.InputStream
import java.text.SimpleDateFormat
import java.util.Locale
import java.util.zip.GZIPInputStream

object XmlTvParser {

    private val DATE_FORMAT_TZ = SimpleDateFormat("yyyyMMddHHmmss Z", Locale.US)
    private val DATE_FORMAT_NO_TZ = SimpleDateFormat("yyyyMMddHHmmss", Locale.US)

    fun parse(inputStream: InputStream, isGzip: Boolean = false): Map<String, List<EpgProgram>> {
        val stream = if (isGzip) GZIPInputStream(inputStream) else inputStream
        val parser = Xml.newPullParser()
        parser.setInput(stream, "UTF-8")

        val result = mutableMapOf<String, MutableList<EpgProgram>>()
        val now = System.currentTimeMillis()
        val minTime = now - 12 * 3600 * 1000L // last 12h
        val maxTime = now + 36 * 3600 * 1000L // next 36h

        var eventType = parser.eventType
        while (eventType != XmlPullParser.END_DOCUMENT) {
            if (eventType == XmlPullParser.START_TAG && parser.name == "programme") {
                val channel = parser.getAttributeValue(null, "channel")
                val startStr = parser.getAttributeValue(null, "start")
                val stopStr = parser.getAttributeValue(null, "stop")

                if (!channel.isNullOrBlank() && !startStr.isNullOrBlank() && !stopStr.isNullOrBlank()) {
                    val start = parseXmlDate(startStr)
                    val stop = parseXmlDate(stopStr)

                    if (start != null && stop != null && stop >= minTime && start <= maxTime) {
                        var title: String? = null
                        var desc: String? = null

                        // Inner tags
                        while (true) {
                            val innerEvent = parser.next()
                            if (innerEvent == XmlPullParser.START_TAG) {
                                when (parser.name) {
                                    "title" -> title = parser.nextText()
                                    "desc" -> desc = parser.nextText()
                                }
                            } else if (innerEvent == XmlPullParser.END_TAG && parser.name == "programme") {
                                break
                            } else if (innerEvent == XmlPullParser.END_DOCUMENT) {
                                break
                            }
                        }

                        if (!title.isNullOrBlank()) {
                            val list = result.getOrPut(channel) { mutableListOf() }
                            list.add(
                                EpgProgram(
                                    channelId = channel,
                                    title = title,
                                    description = desc,
                                    startTime = start,
                                    endTime = stop
                                )
                            )
                        }
                    }
                }
            }
            eventType = parser.next()
        }

        // Sort each channel's programs by startTime
        return result.mapValues { (_, progs) -> progs.sortedBy { it.startTime } }
    }

    private fun parseXmlDate(dateStr: String): Long? {
        val trimmed = dateStr.trim()
        return try {
            if (trimmed.length >= 15 && (trimmed.contains("+") || trimmed.contains("-"))) {
                DATE_FORMAT_TZ.parse(trimmed)?.time
            } else {
                val clean = trimmed.take(14)
                DATE_FORMAT_NO_TZ.parse(clean)?.time
            }
        } catch (_: Exception) {
            null
        }
    }
}

package com.replayer.data

import android.content.Context
import android.content.SharedPreferences
import com.replayer.model.EpgProgram
import com.replayer.model.IptvChannel
import com.replayer.network.iptv.M3uParser
import com.replayer.network.iptv.XmlTvParser
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.launch
import kotlinx.coroutines.withContext
import kotlinx.serialization.encodeToString
import kotlinx.serialization.json.Json
import okhttp3.OkHttpClient
import okhttp3.Request
import java.io.File
import java.util.concurrent.TimeUnit

class IptvManager(private val context: Context) {

    private val prefs: SharedPreferences =
        context.getSharedPreferences("replayer_iptv", Context.MODE_PRIVATE)

    private val client = OkHttpClient.Builder()
        .connectTimeout(15, TimeUnit.SECONDS)
        .readTimeout(30, TimeUnit.SECONDS)
        .build()

    private val json = Json { ignoreUnknownKeys = true }
    private val scope = CoroutineScope(Dispatchers.IO)

    private val _channels = MutableStateFlow<List<IptvChannel>>(loadCachedChannels())
    val channels: StateFlow<List<IptvChannel>> = _channels.asStateFlow()

    private val _favoriteChannelIds = MutableStateFlow<Set<String>>(loadFavoriteChannelIds())
    val favoriteChannelIds: StateFlow<Set<String>> = _favoriteChannelIds.asStateFlow()

    private val _epgMap = MutableStateFlow<Map<String, List<EpgProgram>>>(emptyMap())
    val epgMap: StateFlow<Map<String, List<EpgProgram>>> = _epgMap.asStateFlow()

    private val _isLoading = MutableStateFlow(false)
    val isLoading: StateFlow<Boolean> = _isLoading.asStateFlow()

    private val _statusMessage = MutableStateFlow<String?>(null)
    val statusMessage: StateFlow<String?> = _statusMessage.asStateFlow()

    init {
        // Load EPG if cached or available
        val savedEpg = getSavedEpgUrl()
        if (!savedEpg.isNullOrBlank()) {
            scope.launch { fetchEpg(savedEpg) }
        }
    }

    fun getSavedPlaylistUrl(): String? = prefs.getString("iptv_playlist_url", null)

    fun getSavedEpgUrl(): String? = prefs.getString("iptv_epg_url", null)

    fun getGroups(): List<String> {
        val groups = _channels.value.map { it.group }.distinct().sorted()
        return listOf("Все", "Избранное") + groups
    }

    fun isFavorite(channelId: String): Boolean = _favoriteChannelIds.value.contains(channelId)

    fun toggleFavorite(channelId: String) {
        val current = _favoriteChannelIds.value.toMutableSet()
        if (current.contains(channelId)) {
            current.remove(channelId)
        } else {
            current.add(channelId)
        }
        _favoriteChannelIds.value = current
        prefs.edit().putStringSet("iptv_favorites", current).apply()
    }

    fun getFavoriteChannels(): List<IptvChannel> {
        val favIds = _favoriteChannelIds.value
        return _channels.value.filter { favIds.contains(it.id) }
    }

    fun getCurrentProgram(channel: IptvChannel): EpgProgram? {
        val map = _epgMap.value
        val list = (channel.tvgId?.let { map[it] }) ?: map[channel.name] ?: return null
        val now = System.currentTimeMillis()
        return list.firstOrNull { it.isCurrent(now) }
    }

    fun saveConfigAndLoad(playlistUrl: String, epgUrl: String?) {
        val cleanPlaylist = playlistUrl.trim()
        val cleanEpg = epgUrl?.trim()?.ifBlank { null }
        prefs.edit()
            .putString("iptv_playlist_url", cleanPlaylist)
            .putString("iptv_epg_url", cleanEpg)
            .apply()

        scope.launch {
            loadPlaylist(cleanPlaylist, cleanEpg)
        }
    }

    suspend fun refreshPlaylist() {
        val url = getSavedPlaylistUrl() ?: return
        val epg = getSavedEpgUrl()
        loadPlaylist(url, epg)
    }

    private suspend fun loadPlaylist(url: String, manualEpgUrl: String?) = withContext(Dispatchers.IO) {
        if (url.isBlank()) return@withContext
        _isLoading.value = true
        _statusMessage.value = "Загрузка плейлиста..."

        try {
            val req = Request.Builder()
                .url(url)
                .header("User-Agent", "RePlayer-TV")
                .build()

            val resp = client.newCall(req).execute()
            if (!resp.isSuccessful) {
                _statusMessage.value = "Ошибка загрузки: HTTP ${resp.code}"
                _isLoading.value = false
                return@withContext
            }

            val bodyStream = resp.body?.byteStream()
            if (bodyStream == null) {
                _statusMessage.value = "Пустой ответ сервера"
                _isLoading.value = false
                return@withContext
            }

            val parseResult = M3uParser.parse(bodyStream)
            _channels.value = parseResult.channels
            saveCachedChannels(parseResult.channels)

            val detectedOrManualEpg = manualEpgUrl ?: parseResult.epgUrl
            if (!detectedOrManualEpg.isNullOrBlank()) {
                prefs.edit().putString("iptv_epg_url", detectedOrManualEpg).apply()
                _statusMessage.value = "Каналов: ${parseResult.channels.size}. Загрузка программы передач..."
                fetchEpg(detectedOrManualEpg)
            } else {
                _statusMessage.value = "Каналов загружено: ${parseResult.channels.size}"
            }
        } catch (e: Exception) {
            _statusMessage.value = "Ошибка: ${e.localizedMessage ?: "Сбой соединения"}"
        } finally {
            _isLoading.value = false
        }
    }

    private suspend fun fetchEpg(epgUrl: String) = withContext(Dispatchers.IO) {
        try {
            val req = Request.Builder()
                .url(epgUrl)
                .header("User-Agent", "RePlayer-TV")
                .build()

            val resp = client.newCall(req).execute()
            if (!resp.isSuccessful) return@withContext

            val stream = resp.body?.byteStream() ?: return@withContext
            val isGzip = epgUrl.endsWith(".gz", ignoreCase = true)
            val parsed = XmlTvParser.parse(stream, isGzip = isGzip)
            _epgMap.value = parsed
            _statusMessage.value = "Каналов: ${_channels.value.size}. Программа передач обновлена."
        } catch (_: Exception) {}
    }

    private fun loadFavoriteChannelIds(): Set<String> {
        return prefs.getStringSet("iptv_favorites", emptySet()) ?: emptySet()
    }

    private fun loadCachedChannels(): List<IptvChannel> {
        return try {
            val file = File(context.cacheDir, "iptv_channels.json")
            if (file.exists()) {
                json.decodeFromString<List<IptvChannel>>(file.readText())
            } else emptyList()
        } catch (_: Exception) {
            emptyList()
        }
    }

    private fun saveCachedChannels(channels: List<IptvChannel>) {
        try {
            val file = File(context.cacheDir, "iptv_channels.json")
            file.writeText(json.encodeToString(channels))
        } catch (_: Exception) {}
    }
}

package com.replayer.data

import android.content.Context
import android.content.SharedPreferences
import com.replayer.model.RecentMedia
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.serialization.encodeToString
import kotlinx.serialization.json.Json

class RecentMediaManager(context: Context) {
    private val prefs: SharedPreferences =
        context.getSharedPreferences("replayer_recent_media", Context.MODE_PRIVATE)

    private val json = Json { ignoreUnknownKeys = true }

    private val _recentList = MutableStateFlow<List<RecentMedia>>(loadRecent())
    val recentList: StateFlow<List<RecentMedia>> = _recentList.asStateFlow()

    private fun loadRecent(): List<RecentMedia> {
        val raw = prefs.getString("recent_media_json", null) ?: return emptyList()
        return try {
            json.decodeFromString<List<RecentMedia>>(raw)
        } catch (_: Exception) {
            emptyList()
        }
    }

    private fun saveRecent(list: List<RecentMedia>) {
        _recentList.value = list
        try {
            val encoded = json.encodeToString(list)
            prefs.edit().putString("recent_media_json", encoded).apply()
        } catch (_: Exception) {}
    }

    fun addRecent(id: String, title: String, uri: String) {
        val current = _recentList.value.toMutableList()
        current.removeAll { it.id == id || it.uri == uri }
        current.add(0, RecentMedia(id = id, title = title, uri = uri, timestamp = System.currentTimeMillis()))
        // Keep last 15 items
        val trimmed = current.take(15)
        saveRecent(trimmed)
    }

    fun removeRecent(id: String) {
        val current = _recentList.value.filterNot { it.id == id }
        saveRecent(current)
    }
}

@Composable
fun IptvScreen(
    onPlayChannel: (IptvChannel) -> Unit,
    onNavigateToSettings: () -> Unit,
    onBackToHome: () -> Unit = {},
    modifier: Modifier = Modifier
) {
    BackHandler(enabled = true) {
        onBackToHome()
    }

    val context = LocalContext.current
    val scope = rememberCoroutineScope()
    val iptvManager = remember { IptvManager(context) }

    val channels by iptvManager.channels.collectAsState()
    val favoriteIds by iptvManager.favoriteChannelIds.collectAsState()
    val epgMap by iptvManager.epgMap.collectAsState()
    val isLoading by iptvManager.isLoading.collectAsState()
    val statusMsg by iptvManager.statusMessage.collectAsState()

    val groups = remember(channels) { iptvManager.getGroups() }
    var selectedGroup by remember { mutableStateOf("Все") }

    val filteredChannels = remember(channels, selectedGroup, favoriteIds) {
        when (selectedGroup) {
            "Все" -> channels
            "Избранное" -> channels.filter { favoriteIds.contains(it.id) }
            else -> channels.filter { it.group == selectedGroup }
        }
    }

    val firstItemFocusRequester = remember { FocusRequester() }

    Column(
        modifier = modifier
            .fillMaxSize()
            .padding(horizontal = 32.dp, vertical = 24.dp)
    ) {
        // Top Header
        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.SpaceBetween,
            verticalAlignment = Alignment.CenterVertically
        ) {
            Column {
                Text(
                    text = "ТВ каналы",
                    style = MaterialTheme.typography.displayLarge
                )
                Text(
                    text = if (channels.isEmpty()) "Плейлист не настроен" else "Каналов: ${channels.size} • $selectedGroup",
                    style = MaterialTheme.typography.bodyMedium,
                    color = TextSecondary,
                    modifier = Modifier.padding(top = 2.dp)
                )
            }

            Row(horizontalArrangement = Arrangement.spacedBy(12.dp)) {
                if (channels.isNotEmpty()) {
                    TvFocusCard(
                        onClick = { scope.launch { iptvManager.refreshPlaylist() } },
                        modifier = Modifier
                            .width(150.dp)
                            .height(44.dp)
                    ) {
                        Row(
                            modifier = Modifier.fillMaxSize(),
                            horizontalArrangement = Arrangement.Center,
                            verticalAlignment = Alignment.CenterVertically
                        ) {
                            if (isLoading) {
                                CircularProgressIndicator(modifier = Modifier.size(18.dp), color = AccentCyan, strokeWidth = 2.dp)
                            } else {
                                Icon(Icons.Default.Refresh, contentDescription = null, tint = AccentCyan, modifier = Modifier.size(18.dp))
                            }
                            Spacer(modifier = Modifier.width(8.dp))
                            Text(text = "Обновить", style = MaterialTheme.typography.bodyMedium)
                        }
                    }
                }

                TvFocusCard(
                    onClick = onNavigateToSettings,
                    modifier = Modifier
                        .width(160.dp)
                        .height(44.dp)
                ) {
                    Row(
                        modifier = Modifier.fillMaxSize(),
                        horizontalArrangement = Arrangement.Center,
                        verticalAlignment = Alignment.CenterVertically
                    ) {
                        Icon(Icons.Default.Settings, contentDescription = null, tint = AccentCyan, modifier = Modifier.size(18.dp))
                        Spacer(modifier = Modifier.width(8.dp))
                        Text(text = "Настройки ТВ", style = MaterialTheme.typography.bodyMedium)
                    }
                }
            }
        }

        Spacer(modifier = Modifier.height(16.dp))

        // Empty Playlist State
        if (channels.isEmpty()) {
            Box(
                modifier = Modifier
                    .fillMaxSize()
                    .padding(bottom = 60.dp),
                contentAlignment = Alignment.Center
            ) {
                Column(
                    horizontalAlignment = Alignment.CenterHorizontally,
                    verticalArrangement = Arrangement.Center
                ) {
                    Box(
                        modifier = Modifier
                            .size(72.dp)
                            .clip(RoundedCornerShape(20.dp))
                            .background(DarkCard),
                        contentAlignment = Alignment.Center
                    ) {
                        Icon(
                            imageVector = Icons.Default.Tv,
                            contentDescription = null,
                            tint = AccentCyan.copy(alpha = 0.7f),
                            modifier = Modifier.size(38.dp)
                        )
                    }
                    Spacer(modifier = Modifier.height(16.dp))
                    Text(
                        text = "Плейлист IPTV не добавлен",
                        style = MaterialTheme.typography.titleLarge,
                        color = TextPrimary
                    )
                    Spacer(modifier = Modifier.height(6.dp))
                    Text(
                        text = "Добавьте ссылку на плейлист M3U / M3U8 в настройках приложения",
                        style = MaterialTheme.typography.bodyMedium,
                        color = TextSecondary
                    )
                    Spacer(modifier = Modifier.height(20.dp))
                    TvFocusCard(
                        onClick = onNavigateToSettings,
                        modifier = Modifier
                            .width(220.dp)
                            .height(48.dp)
                    ) {
                        Box(modifier = Modifier.fillMaxSize(), contentAlignment = Alignment.Center) {
                            Text(
                                text = "Настроить IPTV",
                                color = AccentCyan,
                                fontWeight = FontWeight.Bold,
                                style = MaterialTheme.typography.bodyLarge
                            )
                        }
                    }
                }
            }
        } else {
            // Categories Row (Horizontal Pills)
            LazyRow(
                modifier = Modifier.fillMaxWidth(),
                horizontalArrangement = Arrangement.spacedBy(10.dp)
            ) {
                items(groups) { group ->
                    val isSelected = group == selectedGroup
                    TvFocusCard(
                        onClick = { selectedGroup = group },
                        modifier = Modifier.height(40.dp)
                    ) {
                        Box(
                            modifier = Modifier
                                .fillMaxHeight()
                                .background(if (isSelected) AccentCyan.copy(alpha = 0.25f) else Color.Transparent)
                                .padding(horizontal = 16.dp),
                            contentAlignment = Alignment.Center
                        ) {
                            Text(
                                text = group,
                                color = if (isSelected) AccentCyan else TextPrimary,
                                fontWeight = if (isSelected) FontWeight.Bold else FontWeight.Normal,
                                style = MaterialTheme.typography.bodyMedium
                            )
                        }
                    }
                }
            }

            Spacer(modifier = Modifier.height(16.dp))

            // Channel List with Televizo-style EPG
            LazyColumn(
                modifier = Modifier.fillMaxSize(),
                verticalArrangement = Arrangement.spacedBy(8.dp),
                contentPadding = PaddingValues(bottom = 32.dp)
            ) {
                itemsIndexed(filteredChannels, key = { _, ch -> ch.id }) { index, channel ->
                    val isFav = favoriteIds.contains(channel.id)
                    val prog = remember(channel, epgMap) { iptvManager.getCurrentProgram(channel) }
                    val isFirst = index == 0

                    TvFocusCard(
                        onClick = { onPlayChannel(channel) },
                        modifier = Modifier
                            .fillMaxWidth()
                            .height(76.dp)
                            .then(if (isFirst) Modifier.focusRequester(firstItemFocusRequester) else Modifier)
                    ) {
                        Row(
                            modifier = Modifier
                                .fillMaxSize()
                                .padding(horizontal = 16.dp),
                            verticalAlignment = Alignment.CenterVertically
                        ) {
                            // Channel Logo or Placeholder
                            Box(
                                modifier = Modifier
                                    .size(52.dp)
                                    .clip(RoundedCornerShape(8.dp))
                                    .background(DarkSurface),
                                contentAlignment = Alignment.Center
                            ) {
                                if (!channel.logoUrl.isNullOrBlank()) {
                                    AsyncImage(
                                        model = channel.logoUrl,
                                        contentDescription = channel.name,
                                        modifier = Modifier.size(44.dp)
                                    )
                                } else {
                                    Icon(
                                        imageVector = Icons.Default.Tv,
                                        contentDescription = null,
                                        tint = AccentCyan,
                                        modifier = Modifier.size(26.dp)
                                    )
                                }
                            }

                            Spacer(modifier = Modifier.width(16.dp))

                            // Channel Title & EPG Program
                            Column(modifier = Modifier.weight(1f)) {
                                Row(verticalAlignment = Alignment.CenterVertically) {
                                    Text(
                                        text = channel.name,
                                        style = MaterialTheme.typography.titleMedium,
                                        color = TextPrimary,
                                        maxLines = 1,
                                        overflow = TextOverflow.Ellipsis
                                    )
                                    Spacer(modifier = Modifier.width(8.dp))
                                    Box(
                                        modifier = Modifier
                                            .clip(RoundedCornerShape(4.dp))
                                            .background(AccentCyan.copy(alpha = 0.15f))
                                            .padding(horizontal = 6.dp, vertical = 2.dp)
                                    ) {
                                        Text(
                                            text = "LIVE",
                                            color = AccentCyan,
                                            fontSize = 10.sp,
                                            fontWeight = FontWeight.Bold
                                        )
                                    }
                                }

                                Spacer(modifier = Modifier.height(4.dp))

                                if (prog != null) {
                                    Row(verticalAlignment = Alignment.CenterVertically) {
                                        Text(
                                            text = "${prog.formattedTimeRange()}  ${prog.title}",
                                            style = MaterialTheme.typography.bodySmall,
                                            color = TextSecondary,
                                            maxLines = 1,
                                            overflow = TextOverflow.Ellipsis,
                                            modifier = Modifier.weight(1f)
                                        )
                                    }
                                    Spacer(modifier = Modifier.height(4.dp))
                                    LinearProgressIndicator(
                                        progress = { prog.progress() },
                                        modifier = Modifier
                                            .width(180.dp)
                                            .height(3.dp)
                                            .clip(RoundedCornerShape(2.dp)),
                                        color = AccentCyan,
                                        trackColor = DarkSurface
                                    )
                                } else {
                                    Text(
                                        text = channel.group,
                                        style = MaterialTheme.typography.bodySmall,
                                        color = TextSecondary
                                    )
                                }
                            }

                            Spacer(modifier = Modifier.width(16.dp))

                            // Favorite Toggle Button
                            Box(
                                modifier = Modifier
                                    .size(36.dp)
                                    .clip(RoundedCornerShape(18.dp))
                                    .background(if (isFav) Color(0xFFFF4081).copy(alpha = 0.2f) else DarkSurface)
                                    .clickable { iptvManager.toggleFavorite(channel.id) },
                                contentAlignment = Alignment.Center
                            ) {
                                Icon(
                                    imageVector = if (isFav) Icons.Default.Favorite else Icons.Default.FavoriteBorder,
                                    contentDescription = "Избранное",
                                    tint = if (isFav) Color(0xFFFF4081) else TextSecondary,
                                    modifier = Modifier.size(20.dp)
                                )
                            }
                        }
                    }
                }
            }
        }
    }
}

private sealed class UpdateUiState {
    object Idle : UpdateUiState()
    object Checking : UpdateUiState()
    object UpToDate : UpdateUiState()
    object NoReleases : UpdateUiState()
    data class Available(val release: ReleaseInfo) : UpdateUiState()
    data class Downloading(val progress: Float) : UpdateUiState()
    data class ReadyToInstall(val apkFile: File) : UpdateUiState()
    data class Error(val message: String) : UpdateUiState()
}

    var isScanningUpnp by remember { mutableStateOf(false) }

    var iptvEpgInput by remember { mutableStateOf(iptvManager.getSavedEpgUrl() ?: "") }

    val iptvStatusMessage by iptvManager.statusMessage.collectAsState()

    var downloadProgress by remember { mutableFloatStateOf(0f) }
    var showChangelogDialog by remember { mutableStateOf(false) }
    var changelogRelease by remember { mutableStateOf<ReleaseInfo?>(null) }
    val updateActionFocusRequester = remember { FocusRequester() }

        if (updateUiState is UpdateUiState.Downloading || updateUiState is UpdateUiState.ReadyToInstall) {
            delay(60)

                updateActionFocusRequester.requestFocus()
            } catch (_: Exception) {}

                discoveredDevices = list
                isScanningUpnp = false
            }
        }

        isScanningUpnp = true

                discoveredDevices = list

        updateUiState = UpdateUiState.Checking

            updateUiState = when (result) {
                is UpdateCheckResult.UpdateAvailable -> UpdateUiState.Available(result.release)
                is UpdateCheckResult.UpToDate -> UpdateUiState.UpToDate
                is UpdateCheckResult.NoReleasesFound -> UpdateUiState.NoReleases
                is UpdateCheckResult.Error -> UpdateUiState.Error(result.message)

private fun getCurrentAppVersion(context: Context): String {
    return try {
        val pInfo = context.packageManager.getPackageInfo(context.packageName, 0)
        pInfo.versionName ?: "0.7.0"
    } catch (e: Exception) {

private fun Context.findActivity(): Activity? {
    var ctx = this
    while (ctx is ContextWrapper) {
        if (ctx is Activity) return ctx
        ctx = ctx.baseContext
    }
    return null

@Composable
fun UpnpBrowseScreen(
    onPlayMedia: (MediaItem) -> Unit,
    onNavigateToSettings: () -> Unit,
    onBackToHome: () -> Unit,
    modifier: Modifier = Modifier,
    initialFolder: Pair<String, String>? = null,
    lastPlayedMediaId: String? = null,
    isPlayerActive: Boolean = false,
    onFolderLoaded: () -> Unit = {},
    onConsumeLastPlayedMediaId: () -> Unit = {}
) {
    val context = LocalContext.current
    val scope = rememberCoroutineScope()
    val serverConfigManager = remember { ServerConfigManager(context) }
    val favoritesManager = remember { FavoritesManager(context) }
    val recentManager = remember { RecentMediaManager(context) }
    val contentDirectory = remember { ContentDirectoryService() }

    val connectedDevice by serverConfigManager.connectedUpnpDevice.collectAsState()
    val favorites by favoritesManager.favorites.collectAsState()

    var currentItems by remember { mutableStateOf<List<MediaItem>>(emptyList()) }
    var folderStack by remember { mutableStateOf<List<Pair<String, String>>>(emptyList()) }
    var isLoadingFolder by remember { mutableStateOf(false) }

    // User preferences: Default view is LIST
    var viewMode by remember { mutableStateOf(ViewMode.LIST) }
    var sortMode by remember { mutableStateOf(SortMode.BY_NAME) }

    val listState = rememberLazyListState()
    val gridState = rememberLazyGridState()

    val firstItemFocusRequester = remember { FocusRequester() }
    val targetItemFocusRequester = remember { FocusRequester() }
    var lastExitTimestamp by remember { mutableLongStateOf(0L) }

    fun loadFolder(controlUrl: String, folderId: String) {
        isLoadingFolder = true
        scope.launch {
            currentItems = contentDirectory.browse(controlUrl, folderId)
            isLoadingFolder = false
        }
    }

    fun openFolder(controlUrl: String, folderId: String, title: String) {
        onConsumeLastPlayedMediaId()
        folderStack = folderStack + Pair(folderId, title)
        loadFolder(controlUrl, folderId)
    }

    // Initialize or switch folder when connectedDevice or initialFolder changes
    LaunchedEffect(connectedDevice, initialFolder) {
        if (connectedDevice != null) {
            val controlUrl = connectedDevice!!.contentDirectoryControlUrl ?: return@LaunchedEffect
            if (initialFolder != null) {
                if (folderStack.lastOrNull()?.first != initialFolder.first) {
                    folderStack = listOf(Pair("0", connectedDevice!!.friendlyName), initialFolder)
                    loadFolder(controlUrl, initialFolder.first)
                    onFolderLoaded()
                }
            } else if (folderStack.isEmpty()) {
                folderStack = listOf(Pair("0", connectedDevice!!.friendlyName))
                loadFolder(controlUrl, "0")
            }
        }
    }

    fun navigateBack() {
        onConsumeLastPlayedMediaId()
        if (folderStack.size > 1) {
            val parentIdx = folderStack.size - 2
            val parentFolder = folderStack[parentIdx]
            folderStack = folderStack.take(parentIdx + 1)
            connectedDevice?.contentDirectoryControlUrl?.let { url ->
                loadFolder(url, parentFolder.first)
            }
        } else {
            onBackToHome()
        }
    }

    BackHandler(enabled = !isPlayerActive) {
        // Prevent accidental multiple back taps within 400ms after closing player from popping folders
        if (System.currentTimeMillis() - lastExitTimestamp < 400) {
            return@BackHandler
        }
        navigateBack()
    }

    // Sorting
    val sortedItems = remember(currentItems, sortMode) {
        when (sortMode) {
            SortMode.BY_NAME -> {
                currentItems.sortedWith(
                    compareBy<MediaItem> { it.type != MediaType.DIRECTORY }
                        .thenBy(String.CASE_INSENSITIVE_ORDER) { it.title }
                )
            }
            SortMode.BY_DATE -> {
                currentItems.sortedWith(
                    compareBy<MediaItem> { it.type != MediaType.DIRECTORY }
                        .thenByDescending { it.dateAdded ?: "" }
                        .thenBy(String.CASE_INSENSITIVE_ORDER) { it.title }
                )
            }
        }
    }

    if (connectedDevice == null) {
        // Not connected state
        Box(
            modifier = modifier
                .fillMaxSize()
                .padding(32.dp),
            contentAlignment = Alignment.Center
        ) {
            Column(
                horizontalAlignment = Alignment.CenterHorizontally,
                verticalArrangement = Arrangement.Center
            ) {
                Box(
                    modifier = Modifier
                        .size(80.dp)
                        .clip(RoundedCornerShape(20.dp))
                        .background(DarkCard),
                    contentAlignment = Alignment.Center
                ) {
                    Icon(
                        imageVector = Icons.Default.Folder,
                        contentDescription = null,
                        tint = AccentCyan,
                        modifier = Modifier.size(42.dp)
                    )
                }
                Spacer(modifier = Modifier.height(20.dp))
                Text(
                    text = "Подключите свой сервер DLNA/UPnP в настройках",
                    style = MaterialTheme.typography.titleLarge.copy(fontWeight = FontWeight.SemiBold),
                    color = TextPrimary
                )
                Spacer(modifier = Modifier.height(8.dp))
                Text(
                    text = "Выберите DLNA сервер (например Keenetic Giga или медиасервер ПК) в меню настроек.",
                    style = MaterialTheme.typography.bodyMedium,
                    color = TextSecondary
                )
                Spacer(modifier = Modifier.height(24.dp))
                TvFocusCard(
                    onClick = onNavigateToSettings,
                    modifier = Modifier
                        .width(220.dp)
                        .height(48.dp)
                ) {
                    Row(
                        modifier = Modifier.fillMaxSize(),
                        horizontalArrangement = Arrangement.Center,
                        verticalAlignment = Alignment.CenterVertically
                    ) {
                        Icon(Icons.Default.Settings, contentDescription = null, tint = AccentCyan, modifier = Modifier.size(20.dp))
                        Spacer(modifier = Modifier.width(8.dp))
                        Text(text = "Перейти в настройки", color = AccentCyan, style = MaterialTheme.typography.bodyMedium)
                    }
                }
            }
        }
        return
    }

    Column(
        modifier = modifier
            .fillMaxSize()
            .padding(horizontal = 32.dp, vertical = 24.dp)
    ) {
        // Header with Breadcrumb and Controls
        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.SpaceBetween,
            verticalAlignment = Alignment.CenterVertically
        ) {
            Column(modifier = Modifier.weight(1f)) {
                Text(
                    text = connectedDevice!!.friendlyName,
                    style = MaterialTheme.typography.displayLarge
                )
                val breadcrumb = folderStack.joinToString(" / ") { it.second }
                Text(
                    text = breadcrumb.ifEmpty { connectedDevice!!.friendlyName },
                    style = MaterialTheme.typography.bodyLarge,
                    color = AccentCyan,
                    maxLines = 1,
                    overflow = TextOverflow.Ellipsis
                )
            }

            Row(
                horizontalArrangement = Arrangement.spacedBy(12.dp),
                verticalAlignment = Alignment.CenterVertically
            ) {
                // View Switcher (List / Grid)
                TvFocusCard(
                    onClick = {
                        viewMode = if (viewMode == ViewMode.LIST) ViewMode.GRID else ViewMode.LIST
                    },
                    modifier = Modifier
                        .width(160.dp)
                        .height(48.dp)
                ) {
                    Row(
                        modifier = Modifier.fillMaxSize(),
                        horizontalArrangement = Arrangement.Center,
                        verticalAlignment = Alignment.CenterVertically
                    ) {
                        Icon(
                            imageVector = if (viewMode == ViewMode.LIST) Icons.Default.ViewList else Icons.Default.GridView,
                            contentDescription = null,
                            tint = AccentCyan,
                            modifier = Modifier.size(20.dp)
                        )
                        Spacer(modifier = Modifier.width(8.dp))
                        Text(
                            text = if (viewMode == ViewMode.LIST) "Вид: Список" else "Вид: Плитка",
                            style = MaterialTheme.typography.bodyMedium,
                            color = TextPrimary
                        )
                    }
                }

                // Sort Switcher (Name / Date)
                TvFocusCard(
                    onClick = {
                        sortMode = if (sortMode == SortMode.BY_NAME) SortMode.BY_DATE else SortMode.BY_NAME
                    },
                    modifier = Modifier
                        .width(170.dp)
                        .height(48.dp)
                ) {
                    Row(
                        modifier = Modifier.fillMaxSize(),
                        horizontalArrangement = Arrangement.Center,
                        verticalAlignment = Alignment.CenterVertically
                    ) {
                        Icon(
                            imageVector = Icons.Default.Sort,
                            contentDescription = null,
                            tint = AccentCyan,
                            modifier = Modifier.size(20.dp)
                        )
                        Spacer(modifier = Modifier.width(8.dp))
                        Text(
                            text = if (sortMode == SortMode.BY_NAME) "Сорт: По имени" else "Сорт: По дате",
                            style = MaterialTheme.typography.bodyMedium,
                            color = TextPrimary
                        )
                    }
                }
            }
        }

        Spacer(modifier = Modifier.height(20.dp))

        Box(modifier = Modifier.fillMaxSize()) {
            if (sortedItems.isEmpty() && !isLoadingFolder) {
                Box(
                    modifier = Modifier.fillMaxSize(),
                    contentAlignment = Alignment.Center
                ) {
                    Text(
                        text = "Папка пуста",
                        style = MaterialTheme.typography.bodyLarge,
                        color = TextSecondary
                    )
                }
            } else if (viewMode == ViewMode.LIST) {
                // Detailed List View
                LazyColumn(
                    state = listState,
                    verticalArrangement = Arrangement.spacedBy(10.dp),
                    contentPadding = PaddingValues(vertical = 8.dp),
                    modifier = Modifier.fillMaxSize()
                ) {
                items(sortedItems.size, key = { sortedItems[it].id }) { index ->
                    val item = sortedItems[index]
                    val isFirst = index == 0
                    val isTarget = item.id == lastPlayedMediaId
                    val isFav = favorites.any { it.id == item.id }

                    val itemFocusModifier = when {
                        isTarget -> Modifier.focusRequester(targetItemFocusRequester)
                        isFirst -> Modifier.focusRequester(firstItemFocusRequester)
                        else -> Modifier
                    }

                    TvFocusCard(
                        onClick = {
                            if (item.type == MediaType.DIRECTORY) {
                                connectedDevice?.contentDirectoryControlUrl?.let { url ->
                                    openFolder(url, item.id, item.title)
                                }
                            } else {
                                recentManager.addRecent(item.id, item.title, item.uri)
                                onPlayMedia(item)
                            }
                        },
                        modifier = Modifier
                            .fillMaxWidth()
                            .height(78.dp)
                            .then(itemFocusModifier)
                    ) {
                        Row(
                            modifier = Modifier
                                .fillMaxSize()
                                .padding(horizontal = 20.dp),
                            verticalAlignment = Alignment.CenterVertically
                        ) {
                            val icon = when (item.type) {
                                MediaType.DIRECTORY -> Icons.Default.Folder
                                MediaType.VIDEO -> Icons.Default.VideoFile
                                MediaType.AUDIO -> Icons.Default.AudioFile
                                MediaType.IMAGE -> Icons.Default.Image
                                MediaType.UNKNOWN -> Icons.Default.VideoFile
                            }
                            Box(
                                modifier = Modifier
                                    .size(44.dp)
                                    .clip(RoundedCornerShape(8.dp))
                                    .background(AccentCyan.copy(alpha = 0.12f)),

                            ) {
                                Icon(
                                    imageVector = icon,
                                    contentDescription = null,
                                    tint = AccentCyan,
                                    modifier = Modifier.size(24.dp)
                                )
                            }

                            Spacer(modifier = Modifier.width(16.dp))

                            Column(modifier = Modifier.weight(1f)) {
                                Text(
                                    text = item.title,
                                    style = MaterialTheme.typography.titleMedium,
                                    maxLines = 1,
                                    overflow = TextOverflow.Ellipsis,
                                    color = TextPrimary
                                )
                                Spacer(modifier = Modifier.height(4.dp))
                                val sizeStr = item.formattedSize()
                                if (sizeStr.isNotEmpty()) {
                                    Spacer(modifier = Modifier.height(2.dp))
                                    Text(
                                        text = sizeStr,
                                        style = MaterialTheme.typography.bodySmall,
                                        color = TextSecondary
                                    )
                                }
                            }

                            // Favorite Heart button for folders
                            if (item.type == MediaType.DIRECTORY) {
                                Box(
                                    modifier = Modifier
                                        .size(36.dp)
                                        .clip(RoundedCornerShape(8.dp))
                                        .background(if (isFav) Color(0xFFFF4081).copy(alpha = 0.15f) else Color.Transparent)
                                        .clickable {
                                            favoritesManager.toggleFavorite(
                                                FavoriteFolder(
                                                    id = item.id,
                                                    title = item.title,
                                                    sourceType = MediaSourceType.UPNP_DLNA,
                                                    serverControlUrl = connectedDevice?.contentDirectoryControlUrl,
                                                    parentId = item.parentId
                                                )
                                            )
                                        },
                                    contentAlignment = Alignment.Center
                                ) {
                                    Icon(
                                        imageVector = if (isFav) Icons.Default.Favorite else Icons.Default.FavoriteBorder,
                                        contentDescription = "Избранное",
                                        tint = if (isFav) Color(0xFFFF4081) else TextSecondary,
                                        modifier = Modifier.size(20.dp)
                                    )
                                }
                            }
                        }
                    }
                }
            }
        } else {
            // Grid View
            LazyVerticalGrid(
                state = gridState,
                columns = GridCells.Adaptive(minSize = 220.dp),
                horizontalArrangement = Arrangement.spacedBy(16.dp),
                verticalArrangement = Arrangement.spacedBy(16.dp),
                contentPadding = PaddingValues(vertical = 8.dp)
            ) {
                items(sortedItems.size, key = { sortedItems[it].id }) { index ->
                    val item = sortedItems[index]
                    val isFirst = index == 0
                    val isTarget = item.id == lastPlayedMediaId
                    val isFav = favorites.any { it.id == item.id }

                    val itemFocusModifier = when {
                        isTarget -> Modifier.focusRequester(targetItemFocusRequester)
                        isFirst -> Modifier.focusRequester(firstItemFocusRequester)
                        else -> Modifier
                    }

                    TvFocusCard(
                        onClick = {
                            if (item.type == MediaType.DIRECTORY) {
                                connectedDevice?.contentDirectoryControlUrl?.let { url ->
                                    openFolder(url, item.id, item.title)
                                }
                            } else {
                                recentManager.addRecent(item.id, item.title, item.uri)
                                onPlayMedia(item)
                            }
                        },
                        modifier = Modifier
                            .fillMaxWidth()
                            .height(130.dp)
                            .then(itemFocusModifier)
                    ) {
                        Column(
                            modifier = Modifier
                                .fillMaxSize()
                                .padding(16.dp),
                            verticalArrangement = Arrangement.Center
                        ) {
                            val icon = when (item.type) {
                                MediaType.DIRECTORY -> Icons.Default.Folder
                                MediaType.VIDEO -> Icons.Default.VideoFile
                                MediaType.AUDIO -> Icons.Default.AudioFile
                                MediaType.IMAGE -> Icons.Default.Image
                                MediaType.UNKNOWN -> Icons.Default.VideoFile
                            }
                            Row(
                                modifier = Modifier.fillMaxWidth(),
                                horizontalArrangement = Arrangement.SpaceBetween,
                                verticalAlignment = Alignment.CenterVertically
                            ) {
                                Icon(icon, contentDescription = null, tint = AccentCyan)

                                Row(verticalAlignment = Alignment.CenterVertically) {
                                    if (item.type == MediaType.DIRECTORY) {
                                        Icon(
                                            imageVector = if (isFav) Icons.Default.Favorite else Icons.Default.FavoriteBorder,
                                            contentDescription = null,
                                            tint = if (isFav) Color(0xFFFF4081) else TextSecondary,
                                            modifier = Modifier
                                                .size(20.dp)
                                                .clickable {
                                                    favoritesManager.toggleFavorite(
                                                        FavoriteFolder(
                                                            id = item.id,
                                                            title = item.title,
                                                            sourceType = MediaSourceType.UPNP_DLNA,
                                                            serverControlUrl = connectedDevice?.contentDirectoryControlUrl,
                                                            parentId = item.parentId
                                                        )
                                                    )
                                                }
                                        )
                                        Spacer(modifier = Modifier.width(8.dp))
                                }
                            }
                            Spacer(modifier = Modifier.height(12.dp))
                            Text(
                                text = item.title,
                                style = MaterialTheme.typography.titleMedium,
                                maxLines = 1,
                                overflow = TextOverflow.Ellipsis
                            )
                            val sizeStr = item.formattedSize()
                            if (sizeStr.isNotEmpty()) {
                                Text(
                                    text = sizeStr,
                                    style = MaterialTheme.typography.bodySmall,
                                    color = TextSecondary
                                )
                            }
                        }
                    }
                }
            }
        }

        if (isLoadingFolder) {
            Box(
                modifier = Modifier
                    .fillMaxSize()
                    .background(Color.Black.copy(alpha = 0.45f)),
                contentAlignment = Alignment.Center
            ) {
                CircularProgressIndicator(color = AccentCyan)
            }
        }
    }
}
}

// 1. Returning from player: focus the played video item and keep focus on it!
    LaunchedEffect(isPlayerActive) {
        if (!isPlayerActive && lastPlayedMediaId != null) {
            val targetIndex = sortedItems.indexOfFirst { it.id == lastPlayedMediaId }
            if (targetIndex >= 0) {
                delay(60)
                try {
                    if (viewMode == ViewMode.LIST) {
                        listState.scrollToItem(maxOf(0, targetIndex))
                    } else {
                        gridState.scrollToItem(maxOf(0, targetIndex))
                    }
                } catch (_: Exception) {}
                delay(80)
                try {
                    targetItemFocusRequester.requestFocus()
                } catch (_: Exception) {}
            }
        }
    }

    // 2. Folder navigation (entering folder or pressing Back): focus first item
    LaunchedEffect(folderStack) {
        if (folderStack.isNotEmpty() && !isPlayerActive) {
            delay(60)
            try {
                if (viewMode == ViewMode.LIST) {
                    listState.scrollToItem(0)
                } else {
                    gridState.scrollToItem(0)
                }
                firstItemFocusRequester.requestFocus()
            } catch (_: Exception) {}
        }
    }

    // 3. Initial folder items loaded
    LaunchedEffect(currentItems) {
        if (!isPlayerActive && lastPlayedMediaId == null && currentItems.isNotEmpty()) {
            delay(50)
            try {
                firstItemFocusRequester.requestFocus()
            } catch (_: Exception) {}
        }
    }
}
