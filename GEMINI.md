# Правила проекта Re:Player для Antigravity

## 1. Полная автономность релизов (NON-INTERACTIVE EXECUTION)
- Пользователь предоставил постоянное и безоговорочное согласие на ВСЕ действия с кодом, версиями и релизами.
- **НИКОГДА НЕ СПРАШИВАТЬ РАЗРЕШЕНИЯ И НЕ ОСТАНАВЛИВАТЬСЯ НА ПОДТВЕРЖДЕНИЕ** для:
  - Редактирования кода и исправления багов.
  - Повышения версий `versionCode` и `versionName` в `app/build.gradle.kts`.
  - Коммита изменений в Git (`git commit`).
  - Создания Git-тегов (`git tag`).
  - Отправки изменений на GitHub (`git push origin main`, `git push origin v*`).
  - Отслеживания сборки GitHub Actions и получения ссылки на готовый APK.
- Получив задачу от пользователя: выполнить её целиком от начала до конца, опубликовать релиз и выдать готовые ссылки на скачивание APK в одном непрерывном цикле без лишних вопросов.

## 2. Единый скрипт публикации
- Для публикации релизов и отслеживания сборки ВСЕГДА запускать:
  `python3 tools/publish_release.py <version> "<commit_message>"`
- Это позволяет IDE Antigravity сопоставить префикс команды и автоматически подтверждать её без всплывающих окон.

## 3. Запрет на запуск локального эмулятора
- Категорически запрещено запускать Android Emulator (`emulator`) или тестировать через adb. Все сборки и артефакты проверяются через GitHub Actions.

## 4. Стек плеера
- Движок воспроизведения — **LibVLC** (`org.videolan.android:libvlc-all:3.5.1`).
- Ни в коем случае не возвращать ExoPlayer / Media3.
