# 🏷️ Promokashka (Промокашка)

> **Мультиплатформенное мобильное приложение для iOS и Android**  
> *Впитывает скидки • Держит в календаре*

---

## 💡 Концепция и нейминг

Название и логотип обыгрывают две гармоничные части:
* **Promo** (*Промо*) — мгновенный поиск и захват акций, купонов, размера скидок и промокодов из любого сырого текста.
* **kashka** (*кашка* / от *промокашка*) — как промокательная бумага бережно впитывает чернила без клякс, так приложение впитывает в себя выгоду до последней капли и ставит событие в системный календарь с напоминанием, чтобы вы успели им воспользоваться.

---

## ✨ Основные возможности

1. **Интеллектуальный NLP-парсинг текста**:
   * **Размер скидки**: процентные (`-30%`, `до -50%`), фиксированные (`500 ₽`, `1000 рублей`), акции вида `1+1`, `2 по цене 1`, `Кешбэк 25%`, `Бесплатная доставка`.
   * **Магазин / Сервис**: определение как по каталогу известных брендов (*Магнит, Самокат, Ozon, ВкусВилл, Золотое Яблоко, Яндекс Лавка, Перекрёсток, Додо Пицца, DNS и др.*), так и по контекстным маркерам (*магазин, сервис, маркетплейс, в приложении...*).
   * **Промокод**: находит явные и скрытые коды (*MAGNIT30, ОСЕНЬ300, BEAUTY20*). Если промокод не требуется (например, скидка действует автоматически на кассе или в приложении), определяет режим *«Автоскидка (без промокода)»*.
   * **Дата окончания действия**: русскоязычные текстовые даты (*«до 21 октября»*, *«по 25 октября включительно»*), цифровые форматы (*21.10.2026*), относительные сроки (*«до конца недели»*, *«до завтра»*, *«только сегодня»*). Рассчитывает оставшиеся дни и статус акции.
   * **Условия использования**: минимальная сумма чека (*«от 1800 рублей»*), канал заказа (*«на доставку»*, *«только в приложении»*), сегмент клиентов (*«на первый заказ»*), товарные категории.

2. **Интеграция с календарём**:
   * 📲 **Нативный системный календарь iOS и Android**: создание событий через EventKit и Android Calendar Provider.
   * 📁 **Универсальный экспорт .ICS**: генерация стандартного RFC 5545 iCalendar файла со встроенными будильниками (*за 24 часа* и *за 3 часа* до конца акции).
   * 🌐 **Google Календарь**: ссылка мгновенного добавления в 1 клик с предзаполненным описанием, местом и датами.
   * 📋 **Быстрое копирование**: копирование промокода в буфер обмена одним касанием.

3. **Лаконичный дизайн и адаптивность**:
   * Чистая, современная эстетика в стиле iOS Human Interface Guidelines и Material You.
   * Полная поддержка ключевых разрешений мобильных телефонов:
     * Компактные смартфоны: iPhone SE / 12 mini / 13 mini (375pt), малые Android (360dp)
     * Базовые флагманы: iPhone 13/14/15/16 (390–393pt), Google Pixel / Galaxy S (412dp)
     * Большие экраны: iPhone Plus / Pro Max (428–430pt)
     * Safe Area Insets, Dynamic Island, навигационная панель Android.
     * Встроенный симулятор экранов при запуске на десктопе/в браузере.

## 🚀 Запуск проекта

### Требования
* Node.js 18+ (протестировано на Node.js v26.4.0)
* npm 9+
* Мобильное приложение **Expo Go** на вашем iPhone или Android (бесплатно в App Store / Google Play), либо эмулятор iOS / Android.

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск на мобильных устройствах и в браузере

* **Запуск Metro Bundler (универсальный QR-код для iOS и Android)**:
  ```bash
  npm run start
  ```
  *Для iOS*: Откройте камеру iPhone и наведите на QR-код в терминале. Приложение откроется в Expo Go.  
  *Для Android*: Откройте Expo Go и отсканируйте QR-код.

* **Запуск веб-версии / симулятора разрешений в браузере**:
  ```bash
  npm run web
  ```

* **Запуск на эмуляторе iOS (macOS)**:
  ```bash
  npm run ios
  ```

* **Запуск на эмуляторе Android**:
  ```bash
  npm run android
  ```

### 3. Запуск тестов парсера
```bash
npm test
```
Тест автоматически проверяет парсинг примера из технического задания:
```
-30% на на доставку от 1800 рублей. Магазин Магнит. Предложение действительно до 21 октября.
```
И верифицирует корректность выделения скидки (`-30%`), магазина (`Магнит`), даты окончания (`21 октября`), условий (`Заказ от 1800 ₽ • На доставку`) и автоскидки.

## 📱 Пример работы

**Входной текст:**
> «-30% на на доставку от 1800 рублей. Магазин Магнит. Предложение действительно до 21 октября.»

**Распознанный результат в Promokashka:**
* 🏪 **Магазин:** Магнит
* 💰 **Размер скидки:** -30%
* 🎟️ **Промокод:** Автоскидка (без промокода)
* 📅 **Действует до:** 21 октября 2026 г. (статус: *Осталось 4 дня*)
* 📋 **Условия:** Заказ от 1800 ₽ • На доставку
* 🗓️ **Действие:** Нажатие кнопки **«Поставить в календарь»** сохраняет напоминание с будильниками за 24 часа и за 3 часа до дедлайна.
