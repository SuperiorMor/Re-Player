# VPortal JSON API — техническая спецификация (для Re:Player 2.0)

Исследовано на базе формата подключения `portal::[key:<API_KEY>]http://<host>/api/v1/`.

## 1. Формат пользовательской ссылки
```text
portal::[key:<API_KEY>]http://<host>/api/v1/
```
- Префикс `portal::` указывает на режим портала.
- Ключ авторизации извлекается из `[key:<API_KEY>]`.
- Базовый URL API — всё, что идёт после `]`.

## 2. Транспорт и авторизация
- **Метод:** `POST` на `<baseUrl>` (GET-запросы возвращают `HTTP 405`).
- **Заголовки:** `Content-Type: application/json`, `Accept: application/json`.
- **Тело запроса:** JSON-объект, обязательно содержащий `"key": "<API_KEY>"`.
- При отсутствии или недействительности ключа/подписки сервер возвращает `HTTP 200` с:
  ```json
  {"type":"error", "description":"subscription required"}
  ```

## 3. Протокол навигации
Каждый элемент ответа (`items`, `controls`) содержит собственный объект `"request"`. Для перехода достаточно взять базовый `{"key": "<API_KEY>"}` и объединить с `"request"` выбранного элемента/контрола.

### A. Корень портала
Запрос:
```json
{"key": "<API_KEY>"}
```
Ответ (`type: "videoportal"`):
- `items`: массив категорий:
  - `type`: `"category"`
  - `title`: например `"фильмы"`, `"сериалы"`, `"мультфильмы"`, `"Аниме"`, `"Спорт"` и др.
  - `request`: `{"cmd": "flicks", "fid": 1, "offset": 0, "limit": 0}`
- `controls`:
  - `search`: `{"request": {"cmd": "search", "query": "{USERINPUT}"}}`
  - `filters`: массив enum-фильтров (`"Год"`, `"Жанр"`), где у каждого варианта есть `title` и `request` (например `{"filter": "on", "years": "2021-2026"}`).

### B. Список фильмов / сериалов в категории
Запрос (поддерживает пагинацию через `offset` и `limit`):
```json
{"key": "<API_KEY>", "cmd": "flicks", "fid": 1, "offset": 0, "limit": 30}
```
Ответ:
- `count`: общее количество элементов.
- `items`: массив карточек:
  - `type`: `"stream"` (фильм / одиночное видео) или `"multistream"` (сериал).
  - `fid`: числовой ID.
  - `title`: название.
  - `img`: полный URL постера (высокое разрешение).
  - `imglr`: полный URL облегчённого постера (превью для списков/сеток).
  - `year`, `duration` (в минутах), `description`, `agelimit`.
  - `fhd`, `4k`, `hdr`: boolean-флаги качества.
  - `url`: для `stream` сразу может приходить прямая ссылка на `master.m3u8`.
  - `request`: `{"cmd": "flick", "fid": 147742}`.

### C. Детальная карточка фильма (`stream`) или сериала (`multistream`)
Запрос:
```json
{"key": "<API_KEY>", "cmd": "flick", "fid": 147742}
```
- **Для фильма (`type: "stream"`):**
  - `url`: ссылка на HLS `master.m3u8`
  - `variants`: словарь качеств (`"720"`, `"1080"`, `"2160"`, `"auto"` → прямые `.m3u8` URL)
  - метаданные (`title`, `img`, `year`, `duration`, `description`, `agelimit`)
- **Для сериала (`type: "multistream"`):**
  - `title`: например `"Название. Сезон 1."`
  - `items`: массив серий (`type: "stream"`, `title: "Серия 1"`, `fid`, `url: ".../master.m3u8"`, `fhd`, `4k`, `hdr`).

## 4. Совместимость с Re:Player
- Все медиа-потоки — стандартный **HLS `.m3u8`**, полностью совместимый с текущим **LibVLC** движком.
- Благодаря `offset` / `limit` каталог загружается лениво страницами без хранения тысяч записей в памяти.
